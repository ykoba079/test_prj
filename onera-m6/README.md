# ONERA M6: calculated airflow as static SPZ

ONERA M6翼について、実際にSU2で3次元定常圧縮性Euler解析を実行し、その結果をBabylon.jsで表示する試作です。ブラウザ内では流体計算をしません。

## 開く

リポジトリのルートをHTTP配信して `/onera-m6/` を開きます。`file://` ではJSONやSPZの読み込みが制限されるためHTTPが必要です。

```powershell
python -m http.server 8037 --bind 127.0.0.1
```

ローカルURL: http://127.0.0.1:8037/onera-m6/

GitHub Pagesに配置する場合は `onera-m6/` 内のHTML、JS、`assets/`、README、ライセンスを公開します。`work/`、`qa/` はローカル専用でGitから除外しています。Babylon.js 8.45.3と解凍ライブラリはCDNから読み込みます。

## 表示

- 気流: 流線上の明るい下流側の頭＋上流側へ薄くなる6個の尾。色は速度、尾の長さにも速度を反映。
- 翼: 同じ解析メッシュから抽出した表面。初期表示は圧力係数Cp。単色／圧力係数Cp／非表示を切り替え。
- 力: 周囲圧力との差による表面の圧力作用の向きを頭と尾で表示。局所の「面積当たりの力」の方向と相対的な大きさを示し、面要素の総力や粘性応力は示さない。
- 対称表示: 実計算は半翼と対称境界。全翼表示はその結果を鏡映したもので、二つの独立した計算ではない。

流速の色範囲は180〜420 m/s、圧力の色範囲はCp -1.2〜+0.6で固定しています。範囲外の値は端の色に飽和します。光学的な重なりや頭の明るさがあるため、画面の色を数値計測に使うものではありません。

## 計算結果

| 項目 | 値 |
|---|---|
| ソルバー | SU2 8.5.0、Windows OpenMP、4スレッド |
| 方程式 | 3次元定常圧縮性Euler、非粘性 |
| 自由流 | Mach 0.8395、迎角3.06°、101325 Pa、288.15 K |
| 自由流速 | 約285.68 m/s |
| 解析格子 | 108,396点、582,752四面体 |
| 密度の最終log10 RMS残差 | -11.01295795 |
| 揚力係数CL | 0.284857842 |
| 抗力係数CD | 0.01196749963（粘性抵抗を含まない） |
| 最後の20反復間のCL変化 | 約2.28e-7 |
| 最後の20反復間のCD変化 | 約2.70e-9 |
| 翼の描画メッシュ | 全翼で36,570頂点、72,908三角形 |
| 気流SPZ | 150,000スプラット、838,969 bytes |
| 力SPZ | 8,100スプラット、50,650 bytes |

初回の56反復で残差-8に達した後、再スタートして54反復追加し-11まで収束させました。最終計算の履歴、ハッシュ、表示条件、制限を `assets/manifest.json` と `assets/convergence.json` に保存しています。残差が収束したことは、格子精度や実験との一致を保証するものではありません。

## 再計算・再生成

Python 3.10を使用しています。公式Windows配布と解析メッシュのSHA256を検査する準備スクリプトを同梱しています。

リポジトリルートで:

```powershell
./onera-m6/scripts/setup.ps1
python onera-m6/scripts/run_solver.py --fresh
python onera-m6/scripts/build_assets.py
```

`--fresh` は一様な自由流から始めます。省略時はローカルに保存済みの解があれば再スタートし、なければ自由流から開始します。ソルバー、解析ログ、保存解は `work/` に残ります。SPZの生成は `assets/` に出力します。新規の実行では反復数やファイルのハッシュが今回の記録と異なる場合があります。

計算値は元の流体四面体の内部で重心座標によって線形補間しています。近傍点の値で翼内部を埋める方法は使っていません。流線は速度方向を中点法でたどり、流体セル内で補間できない点では停止します。1,176本の半翼側の流線から頭と尾の束を均等に選び、全翼でちょうど150,000スプラットを生成します。個数調整の最後の束のみ尾を短くしています。同じ変換で翼・気流・力を `(x,y,z) → (x,z,-y)` に回転します。

SPZはv2、SH degree 0。写真からの学習は使わず、計算点・向き・大きさ・色・不透明度を直接符号化しています。位置の最大量子化誤差は約0.000122 mです。

## 検証と制限

- SU2の正常終了と収束条件を確認。
- 保存解の点ID・座標と元メッシュの一致、密度・圧力の正値を確認。
- 保存解から復元した速度・Cpが、SU2自身のVTK出力と丸め精度内で一致することを確認。
- 200個の流体セル中心で補間値を検査。最大絶対誤差は約4.3e-14。
- SPZの解凍サイズ・点数・位置量子化を検査。
- 専用のヘッドレスEdgeで実描画、圧力／力／半翼切替、上面視点、390px幅を確認。ソフトウェアWebGLによる検査であり、実スマートフォンの速度測定ではない。
- 粘性・摩擦・境界層・剥離・失速は扱わない。格子収束や実験値との照合は未実施。
- 定常流線の静止表現であり、非定常の渦や粒子の時間履歴を計算したものではない。
