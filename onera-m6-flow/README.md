# ONERA M6 — 気流の粒子表示

保存済みのSU2定常Euler解析の数値結果を、通常のメッシュ粒子で表示するページです。静止したGaussian Splattingの描画とそのメニューを撤去し、SPZファイルは読み込みません。元の `/onera-m6/` は変更していません。

## 表示とメニュー

- 自由流速は約204 / 238 / 272 / 286 / 306 m/sの5条件。初期表示は286 m/sと翼面圧力分布です。
- 気流は半翼8,000粒子、対称反映で最大16,000粒子。解析情報の表示数は実際に表示している粒子の合計です。
- 基本設定は計算条件・粒子の一時停止・翼の色・視点。詳細設定、解析情報、保存・共有は折りたたみます。
- 粒子と翼は常時表示し、全翼を表示します。全翼は半翼の計算結果を対称反映したもので、左右を独立に計算しているわけではありません。
- 断面表示・断面位置・断面厚さ・断面用視点、粒子・翼・全翼の表示チェック、速度フィルターの下限／上限は撤去しました。
- 速度フィルターは数値速度を使用し、「速い・遅い」は自由流速の±5%と比較します。「全表示」は無条件でフィルターを解除します。
- 圧力作用の矢印も通常メッシュです。翼がマッハ表示でも、矢印用のCp凡例を別に表示します。
- 等マッハ線は0.05刻み、白線はM＝1です。翼表面の超音速面積率は頂点マッハ数を面内で線形補間した概算。臨界Cp*は等エントロピー理論の参考値として、解析情報へまとめています。
- GIFは現在の視点で640×480、3秒。HTMLメニューは含みません。

## 数値データと制限

`../onera-m6/scripts/export_particle_fields.py` で既存のSU2保存解から変換しています。新しいシミュレーションは行っていません。速度は元の流体四面体内で重心座標補間し、98×69×56点の直交格子へ出力。流体領域外の値はNaNです。ブラウザーでは格子の速度を三線形補間し、粒子を中点法で進めます。欠損格子や翼内部へ入る粒子は上流へ再配置し、値を自由流で埋めたり、色から速度を逆算したりしません。

翼面マッハ数は `|v| / sqrt(gamma*p/rho)` として、SU2の速度・圧力・密度から直接求めます。Cpの等エントロピー換算ではありません。圧力作用の矢印は、隣接流体セルで向きを確認した表面法線と周囲との差圧から作ります。表示長さには視認性のための下限・上限があり、画面で数値計測する用途ではありません。

速度場は定常・非粘性です。動く粒子はその速度場のスロー表示で、非定常解析や実際の粒子時間履歴ではありません。粘性・摩擦・境界層・剥離・失速を扱いません。格子収束や実験検証は未実施です。表示用の速度格子も粗いため、翼近傍の細かな構造は再現しきれません。

数値データは `assets/` にあり、速度格子はgzip圧縮のlittle-endian Float32 xyz、x方向が最速の並びです。各条件のmanifestにハッシュ・補間検査・収束・数値範囲を記録しています。CDNからBabylon.js 8.45.3とGIFエンコーダを読み込みます。WebGL 2、DecompressionStream、HTTP/HTTPS配信が必要です。
