# 日本地図の出典

Source: https://github.com/dataofjapan/land/blob/master/japan.geojson
Original: 地球地図日本（国土地理院）
Retrieved: 2026-09-15

表示用に各リングをDouglas-Peucker（0.006度）で簡略化し、座標を小数5桁へ丸めています。都道府県は元データのid（JIS都道府県コード）で対応。緯度経度から簡易平面投影でSVGを描画し、全国図は東経122〜147度・北緯23.5〜46度付近の主要部を表示。都道府県選択時は最大ポリゴンの範囲に拡大します。一部離島は表示範囲外です。簡略化された参考図で、測量用・最新の行政境界確認用ではありません。
