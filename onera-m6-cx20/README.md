# ONERA M6 — CX20さん改造版のHTML移植

ユーザー提供のCX20さんによるBabylon.js Playgroundコードを、GitHub Pagesで動く独立したHTMLページに移植しています。元の `/onera-m6/` は変更していません。

## 機能

- 5段階の計算済み速度条件を切り替え
- 翼面の圧力係数・局所マッハ数・等マッハ線・音速線
- 翼幅方向の断面スラブと断面視点
- 速度帯による気流スプラット・動く粒子の絞り込み
- 半翼8,000粒子のアニメーション、再生速度・停止・リセット
- 640×480、3秒のGIF保存

初期表示はCX20さんのコードと同じく「マッハ数の翼面＋動く粒子」です。静止した気流スプラットは表示パネルから有効にできます。

## 移植とデータ

`demo.js` は提供されたPlaygroundコードを基にしています。改造・機能追加はCX20さん、元のCFD/SPZデモとHTMLへの移植はこのリポジトリで行っています。移植ではエンジンとcanvasの引数化、相対データURL、確認用のscene metadataを追加しました。HTML側はBabylon.jsとGUIを同じ8.45.3に固定し、起動・描画ループ・画面サイズ変更・エラー表示・スマートフォンのパネル開閉を担当します。

解析データは `../onera-m6/assets/` を共有します。このページだけを別の場所へ移す場合も、隣に元の `onera-m6/assets/` が必要です。新しいCFD計算は行っていません。動く粒子の速度場はSPZの位置・方向・色からブラウザーで復元した近似で、SU2の元の速度場を直接使うものではありません。局所マッハ数はCpからの等エントロピー換算であり、衝撃波後の領域を含めて正確な局所マッハ数を保証するものではありません。

HTTPでリポジトリを配信し `/onera-m6-cx20/` を開きます。WebGL 2とDecompressionStreamが必要です。Babylon.js・GUI・GIFエンコーダは外部CDNから取得するため、インターネット接続が必要です。計算・元メッシュの出典とライセンスは [元デモの説明](../onera-m6/README.md) を参照してください。
